# Что нового в этом обновлении

- Исправлен ввод текста: теперь при `напечатай ...` бот делает `Ctrl+V` **самым последним** шагом (сначала обычный ввод, потом `Shift+Insert`, и только затем `Ctrl+V`).
- Исправлен режим диалога: бот сначала пытается ответить через API LM Studio, затем только при ошибке пробует ручной режим окна LM Studio.
- Исправлен ручной режим LM Studio: бот больше не должен «повторять ваш запрос» как ответ — добавлена фильтрация совпадения с исходным вопросом.
- Расширено распознавание команды списка приложений (`список открытых приложений`, `покажи открытые приложения`).

## Доступные команды

### Режимы
- `режим диалога`
- `режим команд`

### Текст
- `напечатай <текст>`
- `введи <текст>`
- `впиши <текст>`
- `набери <текст>`
- `сотри текст`
- `сотри весь текст`
- `удали весь текст`
- `очисти текст`
- `очисти всё`
- `отправь`

### Окна и приложения
- `список открытых приложений`
- `покажи открытые приложения`
- `какие окна открыты`
- `переключись на <окно>`
- `активируй <окно>`
- `закрой окно <окно>`
- `запусти <приложение>` *(только с рабочего стола)*

### Экран / ИИ
- `что на экране ...`
- `проанализируй экран ...`
- в **режиме диалога**: любой вопрос в свободной форме

### Прочее
- `стоп`
- `выход`
- `заверши`

## CLI
- `python assistant.py`
- `python assistant.py --ask "вопрос"`
- `python assistant.py --ask-screen "вопрос по экрану"`
- `python assistant.py --list-voices`
