# Голосовой помощник для ПК (Вовчик)

Теперь Вовчик запускается с **небольшим статус-окном**:
- окно открывается первым;
- показывает текущий статус бота (загрузка / слушаю / анализирую экран / остановлен);
- есть кнопки **Старт**, **Стоп**, **Выход**.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python assistant.py
```

После запуска появится окно управления. Нажми **Старт**, чтобы включить микрофон.

## Что исправлено

- Улучшено переключение окон: поиск по открытым окнам + fallback через `wmctrl` / `xdotool` на Linux.
- Добавлен анализ открытых приложений (команда списка окон).
- Добавлена отправка напечатанного сообщения (`Enter`).
- Ввод текста работает через буфер обмена (`Ctrl+V`) — больше не вставляется один пробел.
- Анализ экрана уточнен в промпте и статусе (видно в GUI).

## Примеры команд (свободные формулировки)

### Окна / приложения
- `открой окно telegram`
- `переключись на браузер`
- `активируй vscode`
- `какие окна открыты`
- `список открытых приложений`

### Ввод и отправка
- `напечатай привет, как дела`
- `введи текст завтра встреча в 10`
- `отправь`
- `вышли сообщение`

### Горячие клавиши
- `нажми ctrl+shift+esc`
- `нажми alt+tab`

### Анализ экрана
- `что на экране`
- `проанализируй экран что за ошибка`
- `посмотри экран и скажи что открыто`

### Остановка
- `стоп`
- `заверши`
- `выключи бота`

## Ollama (чтобы Вовчик видел экран)

1. Запусти Ollama:
   ```bash
   ollama serve
   ```
2. Скачай vision-модель:
   ```bash
   ollama pull llava
   ```
3. Проверь отдельно (без микрофона):
   ```bash
   python assistant.py --ask-screen "что сейчас на экране?"
   ```

## Дополнительно

```bash
python assistant.py --list-voices
```

Показывает доступные голоса `pyttsx3`.

## Примечания

- Для Linux может понадобиться `portaudio` для `PyAudio`.
- Для более стабильной активации окон на Linux можно установить:
  - `wmctrl`
  - `xdotool`
