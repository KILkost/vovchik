# Что нового в этом обновлении

- Исправлен приоритет режима диалога: теперь бот **сначала** отправляет вопрос в LM Studio через API, и только при ошибке пробует ручную отправку в окно LM Studio.
- Исправлен ввод текста: добавлены 3 шага ввода — `Ctrl+V`, затем `Shift+Insert`, затем посимвольный ввод.
- Исправлено удаление текста: команды на очистку снова работают, включая `сотри весь текст` / `удали весь текст`.
- Исправлена команда списка приложений: добавлено распознавание формулировки `список открытых приложений`.

## Доступные команды

### Режимы
- `режим диалога`
- `режим команд`

### Текст
- `напечатай <текст>`
- `введи <текст>`
- `впиши <текст>`
- `набери <текст>`
- `сотри текст`
- `сотри весь текст`
- `удали весь текст`
- `очисти текст`
- `отправь`

### Окна и приложения
- `список открытых приложений`
- `какие окна открыты`
- `переключись на <окно>`
- `активируй <окно>`
- `закрой окно <окно>`
- `запусти <приложение>` *(запуск с рабочего стола)*

### Экран / ИИ
- `что на экране ...`
- `проанализируй экран ...`
- в **режиме диалога**: любой вопрос в свободной форме

### Прочее
- `стоп`
- `выход`
- `заверши`

## CLI
- `python assistant.py`
- `python assistant.py --ask "вопрос"`
- `python assistant.py --ask-screen "вопрос по экрану"`
- `python assistant.py --list-voices`
