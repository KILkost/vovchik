# Голосовой помощник для ПК

Этот помощник умеет:
- слушать голос и выполнять команды **в свободной форме** (не только по одной точной фразе);
- активировать окна приложений;
- вводить текст в активное окно;
- нажимать горячие клавиши;
- анализировать скриншот экрана через Ollama vision-модель (`llava`).

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python assistant.py
```

## Примеры команд (можно говорить похожими словами)

### Переключение окна
- `открой окно telegram`
- `переключись на браузер`
- `активируй vscode`

### Ввод текста
- `напечатай привет, как дела`
- `введи текст: завтра созвон в 10`
- `набери это сообщение`

> Вставка текста делается через буфер обмена (`Ctrl+V`), поэтому русский текст больше не превращается в пробелы.

### Горячие клавиши
- `нажми ctrl+shift+esc`
- `нажми alt+tab`

### Анализ экрана
- `что на экране`
- `проанализируй экран что открыто в браузере`
- `посмотри экран и скажи какая ошибка`

### Остановка
- `стоп`
- `заверши`
- `закрой ассистента`

## Чтобы Вовчик видел экран (Ollama)

1. Запусти Ollama:
   ```bash
   ollama serve
   ```
2. Скачай vision-модель:
   ```bash
   ollama pull llava
   ```
3. Проверь анализ экрана без голоса:
   ```bash
   python assistant.py --ask-screen "что сейчас на экране?"
   ```

Если в ответе модель пишет, что не может видеть экран:
- проверь права на захват экрана (macOS: `Screen Recording`, Linux Wayland: ограничения, лучше X11);
- проверь, что скриншот реально доступен в твоей сессии;
- попробуй другой vision-чек: `python assistant.py --ask-screen "опиши изображение"`.

## Доп. команды

```bash
python assistant.py --list-voices
```

Показывает доступные голоса `pyttsx3`, чтобы выбрать нужный.

## Примечания

- Для Linux может понадобиться установка `portaudio` для `PyAudio`.
- Для более стабильного переключения окон на Linux можно установить одну из утилит:
  - `wmctrl`
  - `xdotool`
