# Голосовой помощник для ПК

Этот пример умеет:
- слушать голосовые команды;
- активировать окна приложений;
- печатать текст и нажимать горячие клавиши;
- делать скриншот экрана и отвечать на вопрос по изображению (через локальную vision-модель Ollama, например `llava`).

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python assistant.py
```

## Команды

Сначала произнесите слово активации: **"ассистент"**, потом команду:

- `открой окно Telegram`
- `напечатай привет, как дела`
- `нажми ctrl+shift+esc`
- `что на экране что изображено в левом верхнем углу`
- `стоп`

## Как подключить и настроить голос бота

По умолчанию используется `pyttsx3` и выбирается первый найденный русский голос.

1. Вывести доступные голоса:
   ```bash
   python assistant.py --list-voices
   ```
2. Скопировать `id` нужного голоса.
3. В `assistant.py` в методе `_configure_voice()` заменить выбор на фиксированный:
   ```python
   self.tts.setProperty("voice", "ВАШ_ID_ГОЛОСА")
   ```

Также можно менять скорость и громкость:

```python
self.tts.setProperty("rate", 175)
self.tts.setProperty("volume", 1.0)
```

## Анализ экрана (Vision)

Нужен запущенный Ollama с моделью зрения.

Пример:

```bash
ollama pull llava
ollama serve
```

Переменные окружения (необязательно):

- `OLLAMA_URL` (по умолчанию `http://127.0.0.1:11434/api/generate`)
- `VISION_MODEL` (по умолчанию `llava`)

## Важно

- Для распознавания речи используется Google Speech Recognition API из `SpeechRecognition`.
- Для Linux может понадобиться установка системных зависимостей `portaudio` для `PyAudio`.
