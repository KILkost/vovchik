# Вовчик (Windows + LM Studio)

## Главное
- Два режима:
  - **режим команд** — ИИ используется только для анализа экрана.
  - **режим диалога** — бот отвечает на любые вопросы.
- В режиме диалога бот сначала пытается **вручную отправить запрос в окно LM Studio** (вставка + Enter), затем озвучивает ответ.
- Если ручной путь не сработал, используется API LM Studio (если доступен).

## Установка
```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск
```powershell
python assistant.py
```

## LM Studio
1. Открой LM Studio.
2. Включи Local Server.
3. Загрузи модель.
4. Бот сам пытается найти endpoint.

## Команды
### Переключение режимов
- `режим диалога`
- `режим команд`

### Работа с текстом
- `напечатай привет`
- `введи текст ...`
- `сотри текст`
- `удали весь текст`
- `отправь`

### Окна/программы
- `список открытых приложений`
- `переключись на telegram`
- `закрой окно telegram`
- `запусти телеграм` *(по ярлыку/файлу только с рабочего стола)*

### Экран
- `что на экране`
- `проанализируй экран какая ошибка`

## CLI
```powershell
python assistant.py --ask "любой вопрос"
python assistant.py --ask-screen "что на экране"
python assistant.py --list-voices
```
